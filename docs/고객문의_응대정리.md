# 넬리아 헤어드라이기 고객문의 응대 정리

2026-10-15

들어온 문의를 주제별로 묶고, 지금 바로 답할 수 있는 것과 수치를 확인해야 답할 수 있는 것을 나눴다. 확인되지 않은 숫자는 짐작하지 않고 빈칸으로 두었다.

## 요약

받은 목록 25줄 중 한 줄은 사내 요청(CS 문의 TOP3 데이터와 스크립트)이고, 실제 고객 문의는 중복을 빼면 24가지다. 그중 지금 그대로 답할 수 있는 것은 5가지뿐이다.

| 구분 | 항목 수 | 지금 할 일 |
| --- | --- | --- |
| 바로 답할 수 있다 | 5 | 아래 절의 문장을 그대로 복사해 보낸다 |
| 법정 기준으로 임시 응대 | 6 | 임시 문장으로 받고, 판매자 정책을 이번 주에 확정한다 |
| 확인 전에는 답할 수 없다 | 13 | 추측해서 답하지 않고 확인 후 회신으로 돌린다 |

**가장 급한 세 가지**

1. KC 안전인증번호와 방송통신기자재 적합등록번호. 인증받았다고만 답하면 같은 문의가 다시 온다. 인증서 사본에서 번호를 그대로 옮기면 끝나는 일이다.
2. A/S 주체와 접수처. 제조사인지 수입사인지, 전화번호가 어디인지가 없으면 고장 문의를 한 건도 닫지 못한다.
3. 반품 왕복 배송비 금액과 회수 택배사. 이 둘이 없으면 변심 반품 접수 자체가 진행되지 않는다.

**추측해서 답하면 안 되는 것.** 인증번호, 소음 dB, 대기전력, 배송비 금액, 보증 기간. 틀린 숫자를 한 번 보내면 그 캡처가 돌아다니고, 표시·광고 문제로 번진다. 모르는 항목은 모른다고 하고 확인 기한을 주는 쪽이 안전하다.

## 제품 사양 문의

상세페이지에 이미 올라가 있는 수치는 그대로 써도 된다. 나머지는 측정값이 없어서 못 답하는 것이지, 어렵게 답할 일이 아니다.

| --- | --- | --- |
| 정격 전압·주파수 | | 제품 명판 확인 필요 |
| 1개월 예상 전기요금 | 소비전력 1,300W, 하루 10분 사용 기준 월 약 6.5kWh가 더 나옵니다 | 전력량은 확정, 금액은 단가 확인 필요 |
| 작동 소음 dB | | 측정값 없음 |
| 대기전력 | | 측정값 없음 |
| 전원 코드 길이 | | 실측 필요 |
| 충전식 여부·배터리 | 유선 전용입니다. 배터리는 들어 있지 않습니다 | 확정 |
| 원룸·야간 사용 적합성 | | 소음 측정값 나온 뒤에 답변 |

**그대로 써도 되는 사양**

- 무게: 코드 제외 291g
- 본체 크기: 250 × 84 × 48mm, 손잡이 지름 38mm
- 모터: 110,000RPM BLDC
- 풍속: 2단 실측 24.7m/s, 1단 10m/s
- 소비전력: 1,300W
- 온도: 35, 60, 80, 110도 네 단계
- 과열 방지: NTC 센서, 바이메탈, 과전류 차단 세 가지

**전기요금을 금액으로 답하지 않는 이유.** 주택용 전기요금은 누진제라 같은 6.5kWh도 그 집의 전체 사용량에 따라 요금이 달라진다. 전력량만 알려 주고, 금액을 묻으면 한전 요금표 기준으로 고객 사용량 구간을 봐야 한다고 안내한다.

**소음 문의가 오면.** 측정값을 확인해 회신드리겠다고 받고, 체감 표현으로 돌려 말하지 않는다. 측정값 없이 조용하다고 쓰면 표시·광고 문제가 된다.

## 설치와 벽 거치 문의

벽 거치가 이 제품의 차별점인데, 정작 설치 문의에 답할 수치가 없다. 거치대 실물을 자로 재면 반나절이면 끝나는 일이다.

| 문의 | 지금 보낼 수 있는 답 | 상태 |
| --- | --- | --- |
| 거치대 치수 | | 실측 필요 |
| 설치·사용 최소 여유 공간 | | 실측 필요 |
| 부착 방식 | 3M 양면으로 붙이는 무타공 방식입니다. 못이나 피스를 쓰지 않습니다 | 확정 |
| 붙일 수 있는 벽 | | 제조사 확인 필요 |
| 떼어낼 때 자국 | | 제조사 확인 필요 |
| 감당 하중 | | 제조사 확인 필요 |

**재면 바로 답이 되는 네 가지.** 거치대의 가로·세로·두께, 거치대에 드라이기를 걸었을 때 벽에서 튀어나오는 깊이, 위아래로 필요한 여유, 콘센트까지의 권장 거리. 이 네 개면 설치 문의의 대부분이 닫히고, 상세페이지 도면 한 장으로 다시 쓸 수 있다.

**하중과 벽면 조건은 실측으로 끝나지 않는다.** 3M 테이프는 벽지 종류에 따라 접착력이 크게 달라지고, 떼어낼 때 벽지가 뜯기면 보상 문제가 된다. 제조사에서 권장 벽면 재질, 권장하지 않는 재질, 제거 방법을 문서로 받아 두고, 그 문장을 그대로 상세페이지와 CS 답변에 쓴다. 구두로 들은 내용을 CS가 옮기면 책임이 우리에게 남는다.

**임시 응대 문장.** 거치대 치수와 필요한 설치 공간은 실측해서 정확한 수치로 회신드리겠습니다. 부착은 3M 양면을 쓰는 무타공 방식이라 벽에 구멍을 내지 않습니다.

## 인증과 안전 문의

인증은 받아 둔 제품인데 CS가 번호를 모른다. 인증서 사본 한 장이면 이 절의 절반이 해결된다.

| 문의 | 지금 보낼 수 있는 답 | 상태 |
| --- | --- | --- |
| KC 인증 유형 | 안전인증으로 표기된 제품입니다 | 확정 |
| KC 안전인증번호 | | 인증서 확인 필요 |
| 방송통신기자재 적합등록번호 | | 등록증 확인 필요 |
| 과열이 걱정된다 | NTC 센서, 바이메탈, 과전류 차단 세 가지가 들어 있습니다 | 확정 |
| 화상 예방 사용 거리 | | 설명서 확인 필요 |
| 연속 사용 시간 제한 | | 설명서 확인 필요 |

**안전인증과 안전확인은 다른 제도다.** 전기용품은 위험도에 따라 안전인증, 안전확인, 공급자적합성확인으로 나뉘고, 이 제품의 표기는 안전인증이다. CS에서 KC 인증 받았습니다라고만 쓰면 어느 제도인지 알 수 없어 다시 묻는 문의가 붙는다. 유형과 번호를 같이 적는다.

**화상과 연속 사용은 설명서에 있을 가능성이 높다.** 제품 설명서나 제조사 사양서에 권장 사용 거리와 연속 사용 한계가 적혀 있다면 그 문장을 그대로 옮긴다. 없으면 제조사에 문서로 요청한다. CS가 20cm쯤 띄우세요 같은 문장을 지어내서 쓰면, 사고가 났을 때 그 문장이 근거로 남는다.

**110도 문의에는 숫자로만 답한다.** 최고 단계가 110도인 것은 맞고, 35도부터 네 단계로 고를 수 있다고 안내한다. 두피 보호, 손상 방지 같은 표현은 쓰지 않는다. 효과를 말하는 순간 실증 책임이 판매자에게 넘어온다.

**임시 응대 문장.** 안전인증과 방송통신기자재 적합등록을 모두 받은 제품입니다. 인증번호는 확인해서 바로 회신드리겠습니다.

## A/S와 불량 처리

A/S는 주체가 정해지지 않으면 아무것도 진행되지 않는다. 제조사 보증인지 수입사 보증인지부터 문서로 정한다.

| 문의 | 지금 보낼 수 있는 답 | 상태 |
| --- | --- | --- |
| A/S 주체 | | 제조사·수입사 중 확정 필요 |
| 무상 보증 기간 | | 확정 필요 |
| 접수 방법과 연락처 | | 확정 필요 |
| 초기 불량 인정 기간 | | 확정 필요 |
| 불량 판정 주체와 소요 기간 | | 확정 필요 |
| 유상 수리 기준과 비용 | | 확정 필요 |
| 부품 교체·판매 | | 확정 필요 |
| 자가 점검 절차 | 아래 순서를 그대로 안내한다 | 임시 확정 |

**법정 최저선을 먼저 확인하고 그 위에서 정한다.** 공정거래위원회 소비자분쟁해결기준은 강제 규정은 아니지만 분쟁이 붙으면 사실상 기준선으로 쓰인다. 전기제품은 품질보증기간 1년, 구입 후 짧은 기간 안에 중요한 하자가 나오면 교환 또는 환급이 통상 기준이다. 다만 정확한 일수는 이 문서에서 원문으로 확인하지 못했으므로, 고시 원문에서 해당 품목을 직접 보고 숫자를 확정해야 한다. 기준보다 불리하게 안내하면 분쟁에서 진다.

**전원이 안 켜진다는 문의 자가 점검 순서**

1. 다른 콘센트에 꽂아 본다. 멀티탭이면 벽 콘센트로 바꾼다.
2. 코드와 플러그에 눌린 자국이나 갈라진 곳이 있는지 본다. 있으면 더 쓰지 말고 바로 접수한다.
3. 바람 세기와 온도 스위치를 모두 중간 단계에 놓고 다시 켜 본다.
4. 뒷면 필터를 떼어 먼지를 턴다. 막히면 과열 차단이 걸려 꺼진다.
5. 플러그를 빼고 30분 식힌 뒤 다시 켜 본다. 과열 차단은 식으면 풀린다.
6. 여기까지 해도 안 켜지면 접수로 넘긴다.

**쓰다가 꺼졌다는 문의.** 고장이 아니라 과열 보호가 작동한 것일 수 있다. 필터 청소와 30분 냉각을 먼저 안내하되, 정상입니다로 끝내지 않는다. 같은 증상이 다시 나오면 그때는 불량이다. 재현 여부를 반드시 되물어 보고 기록에 남긴다.

**증빙 요건은 미리 정해 둔다.** 파손·오염 접수 때 사진을 몇 장, 어떤 각도로, 박스를 포함할지를 정해 두지 않으면 고객이 사진을 두 번 찍게 되고, 그것이 불만으로 남는다. 네 장으로 고정하는 것을 권한다. 제품 전체 1장, 손상 부위 근접 1장, 박스와 운송장 1장, 구성품 전체 1장.

## 반품과 교환

반품 문의는 법정 기준이 있어서 지금도 절반은 답할 수 있다. 그 위에 올릴 금액과 택배사만 정하면 나머지도 닫힌다.

**법정 기준 (전자상거래 등에서의 소비자보호에 관한 법률 제17조, 제18조)**

| 문의 | 법정 기준 | 우리가 할 수 있는 것 |
| --- | --- | --- |
| 변심 반품 기간 | 제품을 공급받은 날부터 7일 이내 | 7일보다 길게만 정할 수 있다 |
| 기산 시점 | 수령일 기준 | 같음 |
| 표시·광고와 다를 때 | 안 날부터 30일, 공급받은 날부터 3개월 이내 | 같음 |
| 개봉 후 반품 | 내용 확인을 위한 포장 훼손은 반품 가능 | 개봉만으로 거절할 수 없다 |
| 반품 불가 사유 | 소비자 책임으로 멸실·훼손, 사용이나 일부 소비로 가치가 크게 줄어든 경우, 시간이 지나 재판매가 곤란한 경우, 주문에 따라 개별 생산된 경우 | 조립·설치 자체는 법정 사유가 아니다 |
| 변심 반송비 | 소비자 부담 | 금액 확정 필요 |
| 하자·오배송 배송비 | 판매자 부담 | 같음 |

**개봉했다는 이유로 반품을 거절하면 진다.** 받은 목록에는 반품 불가 조건에 개봉과 설치가 들어 있는데, 법은 내용을 확인하려고 포장을 뜯은 경우를 반품 불가 사유에서 명확히 뺀다. 거절할 수 있는 건 사용 흔적으로 가치가 실제로 떨어졌을 때고, 그 입증은 판매자가 한다. CS 문구에서 개봉 시 반품 불가라는 문장을 혹시 쓰고 있다면 지금 없앤다.

**우리가 정해야 답이 나오는 네 가지**

| 항목 | 정해야 할 값 |
| --- | --- |
| 왕복 배송비 | 편도 금액과 왕복 금액 |
| 도서산간 추가 비용 | 지역 구분과 금액 |
| 회수 택배사 | 택배사명, 배송 택배사와 같은지 |
| 감가 공제 기준 | 포장재 훼손 시, 구성품 일부 사용 시 공제 방식 |

**감가 공제는 미리 고지한 것만 쓸 수 있다.** 포장을 뜯었다는 이유만으로 금액을 깎으면 분쟁에서 불리하다. 공제할 수 있는 것은 소비자 책임으로 가치가 실제로 떨어졌을 때이고, 공제율을 상세페이지와 반품 안내에 미리 적어 두지 않으면 적용하기 어렵다.

**상세페이지에 먼저 적어 두어야 하는 것.** 청약철회 기간, 반송비 부담자, 반품 주소, 청약철회가 제한되는 경우. 적어 두지 않으면 나중에 반품 불가를 주장해도 받아들여지지 않는다. 이건 CS의 일이 아니라 상세페이지의 일이다.

**필터가 소모품인지부터 정한다.** 씻어서 계속 쓰는 것이면 세척 주기와 방법만 안내하면 끝나고, 주기적으로 갈아 끼우는 것이면 가격과 구매처가 있어야 한다. 둘 중 무엇인지 정해지지 않으면 같은 문의가 계속 들어온다. 사용자 입장에서도 물로 씻어도 되는지가 가장 궁금한 대목이다.

**옵션 차이는 CS가 아니라 판매 화면에서 끝내는 것이 맞다.** 같은 설명을 CS가 매번 반복하고 있다면, 그건 상세페이지에 비교표 한 장이 빠졌다는 뜻이다.

## 바로 쓰는 응대 스크립트

확인이 끝나기 전에도 문의는 닫을 수 있어야 한다. 아래 문장을 그대로 복사해 쓰고, 빈칸이 채워지면 빈칸만 바꾸면 된다.

**모르는 항목을 받았을 때 쓰는 기본틀.** 문의 주신 항목은 정확한 수치로 안내드려야 해서 확인 후 회신드리겠습니다. 늦어도 O월 O일까지 답변드리겠습니다. — 기한을 반드시 같이 준다. 기한 없는 확인 후 회신은 재문의를 부른다.

| 상황 | 보낼 문장 |
| --- | --- |
| 전기요금 | 소비전력은 1,300W입니다. 하루 10분 쓰시면 한 달에 약 6.5kWh가 더 나옵니다. 요금은 가정의 전체 사용량 구간에 따라 달라져 금액으로는 안내드리기 어렵습니다 |
| 충전식인지 | 유선 전용 제품입니다. 배터리는 들어 있지 않습니다 |
| 소음 | 측정값을 확인해 회신드리겠습니다. 수치 없이 조용하다고 말씀드리기는 어렵습니다 |
| KC 인증 | 안전인증과 방송통신기자재 적합등록을 모두 받은 제품입니다. 인증번호는 확인해 바로 회신드리겠습니다 |
| 과열 걱정 | NTC 센서, 바이메탈, 과전류 차단 세 가지 보호 장치가 들어 있습니다 |
| 벽 부착 | 3M 양면으로 붙이는 무타공 방식이라 벽에 구멍을 내지 않습니다. 거치대 치수와 필요한 설치 공간은 실측해 회신드리겠습니다 |
| 변심 반품 | 받으신 날부터 7일 이내 반품 가능합니다. 단순 변심 반송비는 고객 부담이며, 금액은 확인해 안내드리겠습니다 |
| 개봉했는데 반품되나 | 내용을 확인하려고 박스를 여신 것은 반품 사유가 되지 않습니다. 접수 도와드리겠습니다 |
| 하자 접수 | 사진 네 장만 보내 주시면 바로 접수하겠습니다. 제품 전체 1장, 손상 부위 가까이 1장, 박스와 운송장 1장, 구성품 전체 1장입니다. 제품 하자일 경우 왕복 배송비는 저희가 부담합니다 |
| 전원이 안 켜짐 | (자가 점검 여섯 단계 안내 뒤) 여기까지 하셔도 켜지지 않으면 접수 도와드리겠습니다 |
| 쓰다가 꺼짐 | 과열 보호가 작동했을 수 있습니다. 뒷면 필터의 먼지를 털어 주시고 플러그를 뺀 채 30분 식힌 뒤 켜 보세요. 같은 증상이 또 나오면 불량으로 접수해 드리겠습니다 |
| A/S 접수처 | 접수 창구를 확인해 오늘 중으로 회신드리겠습니다 |

**쓰면 안 되는 문장**

- 원래 그렇습니다, 정상입니다. 재현되는 증상에 쓰면 그대로 분쟁 근거가 된다.
- 개봉하셔서 반품이 어렵습니다. 법정 기준에 어긋난다.
- 조용합니다, 두피에 좋습니다, 머리가 덜 상합니다. 측정값과 실증 자료가 없으면 표시·광고 문제가 된다.
- 아마 그럴 겁니다. 추측한 숫자는 캡처로 남아 돌아다닌다.
