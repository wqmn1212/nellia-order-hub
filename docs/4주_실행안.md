# 넬리아 헤어드라이기 4주 실행안

2026-11-08 작성 · 기간 11/9(월) ~ 12/5(토)

가격을 60,280원 상시가로 내린 시점에서 다시 짠 계획이다. 목표는 매출이 아니라 **광고를 다시 켤 수 있는 상태를 만드는 것**이다. 지금은 팔수록 손해라서 광고를 켤 수 없다.

## 고정된 숫자

이 문서의 모든 판단은 아래 값을 기준으로 한다. 값이 바뀌면 계획도 다시 봐야 한다.

| 항목 | 값 | 비고 |
| --- | ---: | --- |
| 판매가 | 60,280원 | 상시가 |
| 원가 | 29,821원 | $22 × 1,355.50 |
| 쿠팡 수수료 | 6,510원 | 10.8% |
| 출고 배송비 | 3,000원 | 무료배송 |
| **대당 마진** | **20,949원** | **34.8%** |
| **손익분기 CPA** | **20,949원** | 이보다 비싸면 팔수록 손해 |
| **손익분기 ROAS** | **288%** | 기존 목표 250%는 이보다 낮다 |
| 교환 1건 손실 | 35,821원 | 판매 1.71대분 이익 |

**채널별 대당 마진** — 쿠팡 20,949원 / 네이버 23,933원 / 자사몰 25,651원.
마진이 얇아져 수수료 차이가 전보다 크게 작동한다. 인스타그램과 인플루언서 링크는 자사몰로 건다.

## 현재 상태

| 지표 | 값 | 판단 |
| --- | ---: | --- |
| 노출 | 122,425회 | 충분하다 |
| 클릭 | 131회 | 934회 노출에 1클릭 |
| CTR | 0.11% | **여기가 막혀 있다** |
| 전환 | 2건 | 표본이 2개라 CVR은 믿을 수 없다 |
| CPA | 50,932원 | 손익분기의 2.43배 |
| 광고 1건당 손익 | **−29,983원** | 팔 때마다 손해 |

노출은 쿠팡이 충분히 줬다. **본 사람이 안 누른다.** 검색 결과에서 보이는 건 썸네일·가격·리뷰·상품명 넷뿐이고, 가격은 방금 고쳤으니 남은 건 셋이다.

## 0주차 — 11/9(월) 즉시

| 할 일 | 담당 | 완료 조건 |
| --- | --- | --- |
| 쿠팡 광고 일시 중지 | 마케팅 | 캠페인 상태 '중지' |
| 목표 ROAS 250% → 300%로 변경 | 마케팅 | 재개 시 적용될 값 설정 |
| 가격 인하 사실을 상세페이지 첫 화면에 표시 | 마케팅 | 이미지 교체 완료 |
| 네이버·자사몰 가격을 60,280원으로 통일 | 운영 | 세 채널 동일가 |

**광고를 멈추는 데 주저할 이유가 없다.** 일평균 2,079원이라 멈춰서 잃는 노출은 작고, 켜 두면 건당 29,983원씩 잃는다.

**가격을 내리고 알리지 않으면 마진만 깎인다.** 지금이 정확히 그 상태다. 이번 주에 반드시 표시한다.

## 1주차 — 11/15(일)~11/21(토) · 리뷰

리뷰가 모든 것의 입구다. 리뷰 없는 무명 브랜드는 아무리 좋은 썸네일을 써도 클릭을 못 받는다.

| 할 일 | 담당 | 완료 조건 |
| --- | --- | --- |
| 오더허브에서 배송 완료 주문 전체 명단 추출 | 운영 | 명단 확보 |
| 리뷰 요청 알림톡·문자 발송 | CS | 전체 발송 완료 |
| 포토리뷰 적립금 설정 | 운영 | 스토어 설정 반영 |
| 받은 리뷰에 48시간 내 답글 | CS | 미답글 0건 |

**발송 모수는 광고 전환 2건이 아니라 지금까지 판 전부다.** 오더허브에 쿠팡·네이버 주문이 동기화되어 있으니 거기서 뽑는다.

요청 문구는 짧게 쓴다.

> 넬리아 드라이기는 잘 쓰고 계신가요?
> 벽에 걸어 두고 쓰시는 느낌이 어떠신지 한 줄만 남겨 주시면 다음 제품 만들 때 참고하겠습니다.

**외부 체험단을 쓸 경우 협찬 표기가 본문 첫 화면에 보여야 한다.** 무상 제공, 원고료, 수수료 중 하나라도 있으면 해당한다. 해시태그 더미나 더보기 안에 숨기면 안 된다. 추천·보증 심사지침 사항이고, 지키지 않으면 광고주인 넬리아가 책임진다.

**목표: 누적 리뷰 10건.**

## 2주차 — 11/22(일)~11/28(토) · 썸네일과 상품명

비용이 거의 들지 않고 효과가 즉시 측정되는 구간이다.

| 할 일 | 담당 | 완료 조건 |
| --- | --- | --- |
| 벽에 걸린 장면으로 대표 썸네일 교체 | 디자인 | 쿠팡·네이버 반영 |
| 상품명 맨 앞에 "무타공 벽걸이" 배치 | 마케팅 | 세 채널 반영 |
| 교체 날짜 기록 | 마케팅 | 전후 비교 기준점 확보 |

**같은 가격대에서 벽 거치를 썸네일에 쓰는 경쟁 상품이 없다.** 검색 결과에서 유일하게 다르게 보이는 방법이다.

이 주에는 **CTR만 본다.** 매출은 아직 보지 않는다. 표본이 모자라 의미가 없다.

## 3주차 — 11/29(일)~12/5(토) · 상세페이지

CVR을 올리는 구간이다. 두 가지를 넣는다.

### (1) W 숫자 함정 막기

블라우풍트가 2400W를 내세운다. 넬리아는 1,300W다. 숫자만 보면 절반도 안 되게 약해 보이고, 고객은 그 변환을 스스로 하지 못한다.

> **전기는 덜 쓰고 바람은 더 셉니다**
> 구형 모터는 전기를 많이 써서 바람을 만듭니다.
> 넬리아는 110,000RPM BLDC 모터로 1,300W만 쓰고 실측 24.7m/s를 냅니다.
> 본체는 코드 빼고 291g입니다.

**경쟁사 제품명을 쓰지 않는다.** "구형 모터"로만 표현한다. 지목하는 순간 표시·광고의 공정화에 관한 법률상 실증 자료가 필요해진다.

### (2) 소음과 냄새를 먼저 말하기

받은 리뷰가 짚은 두 가지다. 숨기면 불만이 되고, 먼저 말하면 솔직함이 된다. **반품이 줄어든다.**

> **처음 쓰실 때 냄새가 날 수 있습니다**
> 제조 과정에서 남은 유분이 열선에 닿으며 나는 것으로, 몇 번 쓰시면 사라집니다.
>
> **조용한 편은 아닙니다**
> 빨리 마르도록 회전수를 높인 구조입니다. 2단 기준 78dB이며, 심야에는 1단을 권합니다.

**교환 1건을 막는 것이 35,821원이다.** 광고로 한 대 파는 것(−29,983원)보다 수익성이 좋다. 지금 마진에서는 반품 방지가 가장 남는 장사다.

### 광고 재개 조건

세 가지가 **모두** 충족될 때만 재개한다. 하나라도 미달이면 2주 더 연장한다.

- [ ] CTR 0.30% 이상
- [ ] 누적 리뷰 10건 이상
- [ ] 상세페이지 첫 화면 교체 완료

재개 시 설정은 다음과 같다.

- 목표 ROAS **300%** (손익분기 288% 위)
- 일 예산은 기존 수준에서 시작, 2주간 유지하며 CPA 관찰
- **CPA가 20,949원을 넘으면 즉시 중지**
